# msb-balanced-hosts.txt
#
# Verbatim mirror of the sbx "balanced" (local-policy) network allow-list.
# Each entry below is a host:port row copied EXACTLY as emitted by
# `sbx policy inspect local-policy` (the "allow ... network" rows). This file
# intentionally does NOT translate wildcards or add protocols — it stays a
# faithful, diffable mirror of the sbx output so a human can audit egress at a
# glance.
#
# This file is the SINGLE SOURCE OF TRUTH an operator edits when the sbx
# "balanced" policy changes. Do not hand-edit downstream translations; edit
# here and let the emitter regenerate.
#
# To re-sync when sbx "balanced" changes:
#   1. Run: sbx policy inspect local-policy
#   2. Copy each `allow ... network` host:port row into the matching group
#      below (verbatim). Do NOT copy the filesystem:read / filesystem:write
#      rows — only the network allow hosts belong here.
#
# How this is consumed: the msb backend adapter
# (_acq_msb_balanced_rules_into in acq.backends/msb.sh) reads this file and
# translates each entry into an msb `--net-rule` egress rule:
#   - a leading `**.` or `*.` becomes an msb domain-suffix match `*.host`
#   - the `:PORT` suffix becomes `:tcp:<port>`
#   - the intra-label glob `crl*.digicert.com` cannot be expressed as a pure
#     domain suffix, so it is broadened to `*.digicert.com` and the adapter
#     emits a warning about the widened match.
# See ADR-0018 for the rationale behind vendoring this mirror.
#
# Re-verify on the quarterly review cadence (per AGENTS.md periodic
# re-verification): re-run `sbx policy inspect local-policy` and diff its
# network allow rows against this file.
